# 电脑端使用指南（无痕掠影 · 本地引擎 · 控制面板）

面向「只想在电脑上把视频下下来」的用户：双击、启动、粘贴网址、选画质、下载。
不需要懂 Python，也不需要手机参与。

> 开发、打包、验收脚本、注入引擎的环境变量这些工程细节，见 [`../desktop/README.md`](../desktop/README.md)。
> 本文件只讲怎么用。

## 1. 它能做什么

- 在**隔离的浏览器**里嗅探网页中的视频（不读你日常浏览器的 Cookie、不用它的登录态）。
- 列出页面里可下载的格式与画质，你选一个，剩下的交给引擎。
- 视频与音频分开的源（常见于高画质），由 FFmpeg 自动合并成一个可播放的 MP4。
- 引擎在电脑上监听一个本地端口，**手机也能连**它（见第 6 节）。

## 2. 怎么启动

### A. 双击 exe（推荐）

双击 `desktop\dist\BrowseGuardEngine.exe`，在「引擎设置」标签里点**「启动」**。

- 首次启动要把约百 MB 的随包文件解压到临时目录，会比之后慢一些，多等十几秒是正常的。
- 点窗口右上角 **X 的行为可在「引擎设置 → 点 × 关闭窗口时」里选**：默认
  **隐藏到托盘**（引擎与下载继续在后台跑）；也可选「每次询问」或「直接退出」。
  无论哪种，托盘菜单里的**「退出」**都会连带把引擎进程一起结束掉。

### B. 源码启动（没打包 / 想改代码时）

```powershell
engine\.venv\Scripts\python.exe -m pip install -r desktop\requirements.txt
engine\.venv\Scripts\python.exe desktop\gui_app.py
```

### C. 纯托盘模式（不想要窗口时）

```powershell
engine\.venv\Scripts\python.exe desktop\launcher.py
```

托盘图标是入口：左键唤起菜单，菜单里能看到局域网地址、启动 / 停止引擎、退出。

## 3. 首次启动先看「环境依赖自检」

这张卡片在「引擎设置」标签里，两行状态：

| 依赖 | 绿色 = 可用 | 红色 = 缺什么，怎么补 |
|---|---|---|
| **FFmpeg** | 显示真实版本号 | 点「浏览…」选你本机的 `ffmpeg.exe`。**不需要改系统 PATH**；引擎会自动取同目录的 `ffprobe.exe` |
| **Playwright Chromium** | 已就绪 | 点「一键安装内核」，下方日志区会实时打印下载过程 |

几点要说清楚：

- 自定义的 FFmpeg 路径会存进 `config.json` 的 `ffmpeg_path`，下次开箱即用；点「清除」回到系统 PATH 查找。
- **路径写错不会偷偷回落**：填了一个不存在的 `ffmpeg.exe`，合并会明确报错，而不是悄悄用系统里另一个版本
  糊过去——否则你会以为自定义版本生效了。
- 浏览器内核**不在 exe 里**，它装在 `%LOCALAPPDATA%\ms-playwright`；换电脑要重装一次。

## 4. 界面导览

窗口固定两块常驻信息：顶部黄色安全警告、底部引擎状态栏。

### 「引擎设置」标签

| 控件 | 用途 |
|---|---|
| 连接地址（大字 + 复制） | 手机上要填的那个地址，点复制直接可用 |
| 监听地址 / 端口 | 默认 `0.0.0.0:8730`。选 `127.0.0.1` 则只有本机能连，手机连不上 |
| 输出目录 | 下载产物落在这里，同时作为引擎允许写入的目录白名单 |
| 网络代理 | 可选。目标站点被网络阻断（嗅探报「连接被重置」）时，填本机代理地址如 `http://127.0.0.1:7890`，引擎的嗅探与下载都经代理出网；留空 = 直连。改完需**重启引擎**生效 |
| 自动启动 / 外观 | 外观支持跟随系统 / 浅色 / 深色 |
| 启动 · 停止 · 查看日志 · 隐藏到托盘 | 「查看日志」开一个实时窗口，出问题先看它 |

端口被占用时会直接红字拒绝启动，不会去抢别人的端口。

### 「下载控制台」标签

1. 把网页地址粘进输入框，点**「开始嗅探」**。
2. 嗅探成功后，画质下拉框会列出真实格式，形如 `1080p · mp4 · h264`；纯音频源显示 `纯音频 · m4a · aac`。
3. 选一档，点**「开始下载」**。下方任务行实时显示进度条、速度、剩余时间。
4. 完成时提示 `✓ 下载完成 · 已保存到 <路径>`；失败则是红字，带错误码（见第 8 节）。

引擎没启动时整页是灰的——这是故意的，先回「引擎设置」点启动。

## 5. 文件下到哪了

默认 `%USERPROFILE%\Videos\BGV`（即 `C:\Users\<你>\Videos\BGV`），可以在「输出目录」改。
下载完成提示里会给完整路径。产物是一个 `.mp4`，音视频已合并，双击就能播。

## 6. 让手机连上电脑

桌面端默认监听 `0.0.0.0`，就是为了让同一 WiFi 下的手机连得上。

1. 电脑上点「启动」，窗口顶部的**连接地址**形如 `http://192.168.31.242:8730`。
2. **放行防火墙**（第一次最常见的坑）：Windows 会弹窗问是否允许，选「允许访问」。
   没弹或点错了，手动加：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 →
   端口 → TCP → 特定本地端口 `8730` → 允许连接 → 起个名（如 `BGV Engine`）保存。
3. **验证**：用手机浏览器打开 `http://<电脑IP>:8730/v1/health`。
   - 看到 `{"status":"ok",...}` → 网络通了，去 App 里填这个地址即可。
   - 打不开 → 回到第 2 步查防火墙，或确认手机和电脑连的是**同一个** WiFi（别一个连 WiFi 一个连热点）。

> **信任边界**：引擎**没有密码**。默认监听 `0.0.0.0` 只是为了让手机连得上，
> 代价是同一局域网内的任何设备都能调它。请只在可信的家庭网络使用，**切勿暴露到公网**。

手机侧的详细步骤见 [`USER_GUIDE_ANDROID.md`](USER_GUIDE_ANDROID.md)。手机上填地址**必须带 `http://`**，
且要填电脑的局域网 IP——填 `http://0.0.0.0:8730` 是连不上的，`0.0.0.0` 只表示「电脑在听所有网卡」。

## 7. 配置文件

位置：源码态是 `desktop/config.json`；exe 打包态是 **exe 同目录**下的 `config.json`。

| 字段 | 默认 | 含义 |
|---|---|---|
| `host` | `0.0.0.0` | `0.0.0.0` 局域网可连 / `127.0.0.1` 仅本机 |
| `port` | `8730` | 监听端口 |
| `output_dir` | `%USERPROFILE%\Videos\BGV` | 产物目录 |
| `auto_start` | `false` | 是否随面板启动引擎 |
| `appearance` | `system` | `system` / `light` / `dark` |
| `ffmpeg_path` | `""` | 空 = 系统 PATH；非空 = 自定义 `ffmpeg.exe` 绝对路径 |

文件损坏时会自动备份成 `config.json.bak` 并回落默认值，不会打不开面板。

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 点「启动」红字报端口占用 | 8730 被别的程序占了。换端口（手机端地址同步改），或先关掉占用者 |
| FFmpeg 一直显示未找到 | 系统 PATH 里没有 `ffmpeg`。点「浏览…」直接选 `ffmpeg.exe`，不用改环境变量 |
| 嗅探一直转圈或超时 | 页面可能是纯前端渲染 / 需要登录。换一个有直链的页面试；看「查看日志」里的具体报错 |
| 下载报 `SSRF_BLOCKED` | 目标地址指向内网或受限网段，引擎按安全策略拒绝。这是保护，不是 bug |
| 下载报 `AUTH_REQUIRED` | 站点要登录态。电脑端不做 Cookie 注入，这类源请在手机端用「按域名授权 Cookie」 |
| 下载报 `DRM_PROTECTED` | 受 DRM 保护的源，明确拒绝，不提供下载入口 |
| 下载报 `FORMAT_UNAVAILABLE` | 选的画质超出体积上限或已下架，换一档再试 |
| 关闭窗口后引擎还在跑 | 默认 X = 隐藏到托盘（为手机联机/后台下载兜底）。想关窗即退，在「引擎设置 → 点 × 关闭窗口时」里选**直接退出** |
| 手机浏览器打不开 `/v1/health` | 九成是防火墙（第 6 节第 2 步）；其次确认监听地址是 `0.0.0.0` 而非 `127.0.0.1` |

## 9. 已知边界

- **无入站鉴权**：不设 Token、不设账号（M15.3 裁决）。由此带来的约束就是第 6 节那条信任边界。
- **不识别部分站点**：B 站一类把视频拆成 `.m4s` 分片的 DASH 站点，引擎的嗅探白名单不认；
  实测 `w3schools` 这类普通页面可以嗅探到 mp4，但下载可能被站点鉴权拒掉。
- **只下点播**：清单里没有 `ENDLIST` 的直播流直接拒绝。
- **输出目录受白名单限制**：只能写到 GUI 里配置的那个目录，防止被当成任意文件写入器。
- **换机器不复现旧结果**：`config.json`、`engine.log`、`preview/`、`dist/*.exe` 都不入库，
  需要在新机器上重新跑一次打包。
