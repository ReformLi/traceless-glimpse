# 手机端使用指南（无痕掠影 · Android）

面向「在手机上抓网页视频」的用户。这个 App 有两种活法：**连电脑引擎**，或者**完全离线自己干**。

> 代码结构、构建细节、测试口径见 [`../android/README.md`](../android/README.md)。
> 本文件只讲怎么装、怎么用、连不上怎么办。

## 1. 两种执行方式

App 内部把「嗅探」与「下载」分开配置，各有两档：

| 环节 | 两档 | 差别 |
|---|---|---|
| **嗅探** | 本机嗅探 / 电脑引擎 | 本机开箱即用；电脑引擎解析更强（能处理更多站点），但要电脑在线 |
| **下载执行者** | 引擎 / 本地直链 | 引擎能把音视频分开的源合并好；本地直链只下**一条直链**，不做合并 |

不想碰电脑：两档都选「本机 / 本地直链」即可离线工作。想要完整画质：电脑上开引擎（见
[`USER_GUIDE_DESKTOP.md`](USER_GUIDE_DESKTOP.md)），手机连过去。

## 2. 安装

本项目没有上架应用商店，APK 需要自己构建：

```powershell
.\gradlew.bat :android:app:assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

把 APK 传到手机安装即可（系统要求 Android 10 / API 29 以上）。首次安装需要允许「安装未知来源应用」。

## 3. 第一次打开：配好连接（可选）

只用本机模式的话，这一步可以跳过。

1. 电脑上先启动引擎，记下窗口里的**连接地址**（形如 `http://192.168.31.242:8730`）。
2. 手机上：**设置 → 引擎连接**，把这个地址填进去，点**「测试连接」**。
3. 顶部状态条变绿显示「已连接 · 引擎 … · 协议 …」就通了。

两个容易填错的地方：

- **必须带 `http://`**，别只填 IP。
- 填的是电脑的**局域网 IP**，不是 `127.0.0.1`（那是手机自己），更不是 `0.0.0.0`
  （那只是电脑的监听状态，手机不认这个地址）。

## 4. 抓一个视频

1. 首页地址栏**粘贴**网页链接（有「粘贴」按钮，直接用剪贴板），点**「嗅探」**。
   也可以切到内置浏览器，边看边让它在后台嗅探。
2. 嗅探结果会列出页面里的视频、音频与 HLS 流。选一条，看画质表。
3. 选一档画质，点下载。任务会进「下载」页，实时显示进度、速度、剩余时间。

下载期间系统通知栏会挂一条进度（设置里的**「下载保活」**默认开着），灭屏也能继续下。

## 5. 下载管理与播放

「下载」页把历史记录当成文件台账：

- **打开 / 分享 / 重命名 / 删除**（可选只删记录，或记录 + 文件），支持批量选择。
- 库里已经不存在的产物会被标出并给对账入口；冷启动还会清理应用沙盒里的孤儿文件。
- 删除用户可见的记录需要二次确认。

点一条已完成记录，用内置播放器全屏播放：

- **手势**：横滑快进 / 快退（整屏约 90 秒）；左半屏上下调亮度，右半屏上下调音量。
- **倍速**：控制条上的倍速按钮，0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0。
- **画中画**：播放中按 Home 会缩成小窗，声音不断；回到 App 恢复。
- **断点续播**：退出时自动记进度。起播 2 秒内不记；看到距结尾 15 秒内或 97% 视为看完，下次从头开始。

## 6. Cookie：默认关，按域名授权

有些直链要站点认出你是登录态（通常是 HTTP 403）。

- 第一次遇到时，App 会弹确认框问「允许读取 `<域名>` 的登录状态吗」。**同意之前，连 Cookie 都不读**。
- 授权后只注入**同一站点**的本机下载请求，不会进任何发给电脑引擎的请求。
- 管理在**设置 → Cookie 授权**，按域列出已授权站点；「撤销」只收回许可，下次会重新问。
  要用系统级清除，用「清除所有 Cookie」（二次确认）。

## 7. 连不上电脑？按这三关排除

**判断标准：用手机浏览器访问引擎的健康检查地址。**

### 第一关：网络通不通

1. 电脑上 `Win + R` → `cmd` → `ipconfig`，找到当前 WiFi 的 **IPv4 地址**（如 `192.168.1.105`）。
2. 确认手机连的是**同一个 WiFi**（别一个连 WiFi、一个连热点）。
3. 手机浏览器打开 `http://<电脑IP>:8730/v1/health`：
   - 显示 `{"status":"ok",...}` → 网络通了，问题在 App 侧配置（回到第 3 节检查地址）。
   - 打不开 → 看第二关。

### 第二关：Windows 防火墙（最常见）

电脑默认会拦外部设备访问 8730。

1. 控制面板 → **Windows Defender 防火墙** → 左侧「高级设置」。
2. 「入站规则」→ 右侧「新建规则」→ **端口** → 下一步。
3. **TCP**，特定本地端口填 `8730` → 下一步。
4. **允许连接** → 一路下一步 → 起名（如 `BGV Engine`）保存。
5. 回手机浏览器刷新，看能不能打开。

### 第三关：明文 HTTP 拦截（现在通常不用管）

包里的 `network_security_config.xml` 默认已放开明文 HTTP（内置浏览器要能打开任意站点）。
先看一眼现场再决定要不要动：

```powershell
Get-Content android\app\src\main\res\xml\network_security_config.xml
```

- 读到 `cleartextTrafficPermitted="true"` → **不用改**。这时还连不上，回第一、二关查地址与防火墙。
- 读到白名单形态（只有 `127.0.0.1` / `localhost`）→ 说明你手里是很旧的包，重新构建安装即可。

> 若确实要手改这个文件：**`<trust-anchors>` 那段别删**。只留 `cleartextTrafficPermitted="true"`
> 会把系统信任锚一起改掉，结果 HTTPS 请求不再认正规证书，连局域网 TLS 引擎也一起连不上。

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 状态条一直「未连接」 | 先在手机浏览器测 `/v1/health`（第 7 节），能通就是地址/端口填错 |
| 电脑没开也能用吗 | 能。嗅探切「本机嗅探」、执行者切「本地直链」，全离线；只是不做音视频合并 |
| 下下来没声音 / 播放器不认 | 音频门禁没过时会**降级保留 `.ts`**，完成卡里会写原因。宁可给 `.ts` 也不给哑巴 `.mp4` |
| 通知栏没有下载进度 | 通知权限没给。设置里会标出来；不影响下载本身 |
| 切换「下载执行者」失败 | 有任务在跑。等它结束或先取消，才能切换 |
| 提示 DRM | 受保护内容，明确拒绝，不提供下载入口 |
| 直播链接下不了 | 只支持点播。清单没有 `ENDLIST` 的直播流会被直接拒绝 |
| 视频列表是空的 | 站点用 blob/MSE 播放，App 不伪造可下载地址——这是故意的 |

## 9. 已知限制

- **不支持 DRM**：SAMPLE-AES / Widevine / FairPlay 一律拒绝并如实提示。
- **只下点播**：直播流不做录制。
- **不引 FFmpeg**：转封装走系统 `MediaExtractor` / `MediaMuxer` 纯拷贝，APK 不因此变大；
  代价是遇到非常规音频（如带 CRC 的 ADTS、HE-AAC/SBR）会降级保留 `.ts`，而不是硬转。
- **连接引擎无鉴权**：引擎不设密码，只在可信家庭局域网使用。
- **下载保活只在模拟器验证过**：真实厂商省电策略下的后台时长未实测。
